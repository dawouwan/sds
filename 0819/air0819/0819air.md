# PRD — 대한민국 지역별 대기질 조회 서비스

> 상태: 초안 v0.1 · 작성일 2026-08-19
> 서비스명 미정 (§11 미결 항목 참조)

---

## 1. 개요

전국 17개 시도의 미세먼지 상황을 지도 형태의 타일에서 한눈에 비교하고, 관심 지역의 24시간 추이와 대기 중 중금속 성분까지 확인할 수 있는 개인용 웹 서비스.

**목표**
- 첫 화면에서 전국 대기질을 동시에 비교할 수 있을 것
- 목적지의 야외 체류 가능 여부를 색만 보고 판단할 수 있을 것
- 기존 날씨 앱에 없는 성분(중금속) 정보를 부가 가치로 제공할 것

**비목표**
- 상업적 운영, 회원 가입, 알림/푸시
- 현재 위치 자동 감지 (초기 범위 제외)
- 대기질 예보 (초기 범위 제외)

---

## 2. 사용자 시나리오

**핵심 시나리오 — 목적지 확인**
다른 도시의 맛집을 방문하기 전, 해당 지역의 대기 상태를 확인한다. 웨이팅이나 골목 도보 등 야외 체류 시간이 있으므로 "괜찮은가 / 나쁜가"의 판정이 우선이다.

**부가 시나리오 — 지역 간 비교**
여러 도시의 상태를 나란히 놓고 비교한다. 첫 화면 자체가 17개 동시 비교 화면이므로 별도 비교 모드가 필요 없다.

**설계 함의**
- 현재 위치보다 임의 지역 탐색이 메인 동선
- 숫자보다 등급 색이 먼저 읽혀야 함
- 지역 간 이동 비용이 낮아야 함 (상세가 열린 상태에서도 다른 타일 탭 가능)

## 4. 등급 체계

**판정 기준: WHO 권고 기준**

| 등급 | PM2.5 (µg/m³) | PM10 (µg/m³) | 색 역할 |
|---|---|---|---|
| 좋음 | 0–15 | 0–30 | success |
| 보통 | 16–25 | 31–50 | accent |
| 나쁨 | 26–50 | 51–100 | warning |
| 매우나쁨 | 51+ | 101+ | danger |

**규칙**
- 화면에 항상 `WHO 기준` 라벨을 병기한다. 국내 예보·포털과 등급이 다르게 표시되는 것이 정상 동작임을 알린다.
- 통합대기환경지수(CAI)는 환경부 산식 기반이라 WHO로 환산할 수 없다. **등급 색을 부여하지 않고 숫자만 표시**하며, 산정 기준이 다름을 주석으로 명시한다.
- 등급 경계값은 클라이언트에서 직접 계산한다 (시도별 평균 응답에 등급 필드가 없을 가능성 대비).

## 5. 화면 구성

### 5.1 메인 — 지리 배치 타일 지도

- 대한민국 해안선을 단순화한 SVG `path` 1개를 배경 윤곽선으로 표시 (외곽선만, 채움 없음). 제주는 별도 타원.
- 17개 시도 타일을 **실제 위경도에 대응하는 절대 위치**에 배치. 격자에 정렬하지 않는다.
- 좌표가 겹치는 쌍(서울·경기·인천, 세종·대전, 울산·부산, 광주·전남)은 최소 간격을 확보하도록 미세 조정한다.
- 타일은 정사각형, 등급 색 배경, 시도명 + 수치 1개.
- 하단에 등급 범례와 측정 기준 시각(`dataTime`)을 표시한다.

**구현 메모**
- 지도 라이브러리·GeoJSON 불필요. 하드코딩된 SVG path 1개 (1KB 미만).
- 타일 위치는 `(경도, 위도) → (%, %)` 변환값을 상수 테이블로 보관.

### 5.2 상세 카드 (길게 눌러 진입)

- 24시간 추이 꺾은선 그래프가 중심.
  - SVG `polyline` 직접 구현 (24포인트, 차트 라이브러리 미사용)
  - 배경에 WHO 등급 밴드(15 / 25 / 50 경계) 옅게 표시
- 그래프 상단에 **측정소 드롭다운**. 기본값은 시도별 대표 측정소 1곳(시도청 소재지 기준, 17개 하드코딩). 변경 시 해당 측정소 시계열 1회 추가 호출.
- 하단 보조 영역: 가스상 4종(O₃·NO₂·CO·SO₂) 접기, 납 농도 및 연간기준 대비 비율.
- 배경은 흐려지되 완전히 가리지 않는다. 상세가 열린 상태에서 다른 타일을 탭하면 즉시 해당 지역으로 전환된다.

## 6. 인터랙션

### 6.1 타일 조작

| 동작 | 결과 |
|---|---|
| 짧게 탭 | 타일이 뒤집히며 다음 면으로 순환 |
| 길게 탭 (400–500ms) | 상세 카드 열림 |

**순환 면 구성 (4면)**

1. PM2.5 — 등급 색
2. PM10 — 등급 색
3. 통합대기환경지수(CAI) — 등급 색 없음, 숫자만
4. 납 — 등급 색 없음, 연간기준 대비 % 및 권역명 표기

> 4면 순환은 현재 면을 알기 어렵다. 타일 내 항목 라벨 또는 도트 인디케이터가 필요하다.

### 6.2 롱프레스 구현 요건

- `user-select: none`, `-webkit-touch-callout: none` 적용
- `contextmenu` 기본 동작 차단 (안드로이드 크롬 대응)
- 임계값 400–500ms, 포인터 이동 10px 초과 시 취소 (스크롤 충돌 방지)
- 데스크톱 입력 매핑은 미결 (§11)

## 7. 갱신 및 캐싱

| 대상 | 서버 캐시 (`s-maxage`) | 비고 |
|---|---|---|
| 에어코리아 실시간 | 10분 | 원본은 1시간 주기 |
| 중금속 | 60분 | 원본은 2시간 주기 |

- Vercel 엣지 캐시를 사용한다. 다수 사용자가 접속해도 원본 호출은 캐시 만료 시 1회.
- 자동 폴링 없음. **수동 새로고침 버튼** 제공.
- 새로고침 버튼은 캐시를 우회하므로 **30초 쿨다운**을 건다 (일일 한도 소진 방지).
- 화면에 항상 응답의 `dataTime`(측정 기준 시각)을 표시한다. 캐시 주기와 무관하게 실제 측정 시각을 알 수 있어야 한다.

## 8. 예외 처리

### 8.1 개별 타일 결측

- 회색 배경 + 점선 테두리 + `–` 표시. **`opacity`로 흐리게 처리하지 않는다** (대비 저하로 판독 불가).
- 탭하면 사유를 안내한다.

| 원인 | 감지 | 사용자 문구 방향 |
|---|---|---|
| 측정소 점검 | 값이 `-` 또는 항목 누락 | 해당 측정소 점검 중 |
| 데이터 없음 | `resultCode` 03 | 해당 시간 자료 없음 |
| 일일 호출 한도 초과 | `resultCode` 22 | 서비스 일시 제한 |
| 네트워크 오류 | HTTP 오류 / 타임아웃 | 연결 실패, 재시도 안내 |

> `resultCode` 22는 개발계정에서 실제 발생 가능성이 높다. 별도 문구 필수.

### 8.2 전체 실패

프록시 응답 자체가 실패하면 지도 대신 오류 상태 화면과 재시도 버튼을 표시한다.

## 9. 비기능 요건

**오프라인**
- Service Worker는 앱 셸(HTML·CSS·JS)만 캐시한다. 데이터는 캐시하지 않는다.
- 오프라인 시 앱 틀만 뜨고 "연결 없음" 안내를 표시한다.
- 배포 후 구버전 셸이 남지 않도록 버전 기반 캐시 무효화를 적용한다.

**성능**
- 첫 화면은 캐시된 요약 1건으로 렌더 (API 호출 0~1회)
- 차트·지도 라이브러리 미사용. 외부 런타임 의존성 최소화

**보안**
- API 인증키는 Vercel 환경변수에만 존재한다. 클라이언트 번들에 절대 포함하지 않는다.
- 모든 공공 API 호출은 `/api/*` 서버 함수를 경유한다 (CORS 및 http/https 혼합 콘텐츠 회피).
- 공공데이터포털 활용신청 시 도메인/IP를 제한하지 않는다. Vercel 서버리스는 출발 IP가 고정되지 않아 `resultCode` 32가 발생한다.

**접근성**
- 타일은 `button` 요소로 구현하고 `aria-label`에 지역명과 수치를 포함한다.
- 등급을 색으로만 전달하지 않는다 (수치 병기).
